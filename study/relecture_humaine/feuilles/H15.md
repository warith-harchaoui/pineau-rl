## Q5. Le code est en lien / Code is linked

Règle : `yes` si l'article donne un lien vers du code (GitHub, GitLab, site du projet). « Code disponible sur demande », « sera publié », « will be made public at <URL> » : `no`. Une page de projet compte `yes` seulement si elle mène à du code ; un miroir anonyme qui contient le code compte `yes` (écarts 6 et 19).

A project page counts `yes` only if it leads to code; an anonymous mirror that contains the code counts `yes` (deviations 6 and 19).*

## Y9. La sensibilité à au moins un hyperparamètre est montrée / Sensitivity to at least one hyperparameter is shown

Règle : `yes` si au moins un hyperparamètre de la méthode est balayé et que le résultat est montré (figure, tableau ou phrase chiffrée). Une ablation de composant ne compte pas : ce n'est pas un hyperparamètre. Compte un hyperparamètre que l'article présente comme tel ; une variante qu'il présente comme un composant reste une ablation. Un paramètre réglé à l'inférence compte s'il est présenté comme un hyperparamètre ; une condition de l'environnement ne compte pas ; le résultat montré doit être une mesure de performance (écarts 14, 17 et 19).

*Rule: `yes` if at least one hyperparameter of the method is swept and the result is shown (figure, table or sentence with numbers). A component ablation does not count: it is not a hyperparameter. A hyperparameter counts if the paper presents it as one; a variant it presents as a component remains an ablation. A parameter set at inference counts if it is presented as a hyperparameter; a condition of the environment does not count; the result shown must be a performance measure (deviations 14, 17 and 19).*

## X8. L'incertitude est calculée sur des entraînements indépendants / The uncertainty is computed over independent training runs

Règle : `yes` si l'incertitude des résultats principaux est calculée entre au moins deux entraînements indépendants (graines) et que l'article le dit (« mean ± std over 5 seeds », « shaded area: standard error across 10 runs ») ; `no` si elle porte sur des épisodes, des déroulements d'évaluation ou des éléments de test seulement, si elle mêle graines et épisodes dans un même écart, ou si sa source n'est pas dite ; `na` si et seulement si X2 vaut `no`.
